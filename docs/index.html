Smart HRMS

Free & open-source Human Resource Management System — attendance tracking, leave management, WFH requests, eSSL biometric integration, reports and Azure AD SSO.

View on GitHub Download

Features

Attendance Management

Real-time attendance dashboard, calendar view and attendance logs with check-in / check-out tracking.

eSSL Biometric Integration

Direct iClock / eTimeTrackLite protocol sync with eSSL biometric devices every minute, plus live view and machine control.

Leave Management

Leave requests, approvals workflow, holidays calendar and time-off hub for employees and managers.

Work From Home

WFH requests and virtual login for remote and hybrid teams.

Employee Management

Employee directory, profiles, roles and device management.

Reports

Attendance and leave reports ready for payroll processing and export.

Secure SSO

Microsoft Azure AD (MSAL) single sign-on plus JWT authentication.

Cloud Ready

Docker, Azure Container Apps, Azure PostgreSQL, Blob and Queue Storage.

Tech Stack

FrontendReact 19, TypeScript, Vite, Tailwind CSS, Recharts, Socket.IO
BackendNode.js, Express, TypeScript, Prisma ORM, Socket.IO
DatabasePostgreSQL (MongoDB supported)
AuthJWT + Azure AD / MSAL SSO
DeploymentDocker, Azure Container Apps, GitHub Actions

Quick Start

git clone https://github.com/anuj7052/smart-hrms.git
cd smart-hrms
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
cd backend && npm install && npm run dev
cd ../frontend && npm install && npm run dev

Why Smart HRMS?

Smart HRMS is a modern, self-hosted alternative to paid HR software. It's built for small and medium businesses in India and worldwide that use eSSL biometric attendance machines and need a free, customizable HR management system.
